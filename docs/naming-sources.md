## 规则

- 按实际详情名识别完整食物词与类别，不按陌生商品 code 取首字。
- 模板包含使用条件；夹薯堡需要汉堡与薯条，无汉堡的选品不生成堡类餐名。
- 名字与口号配对；不拼接独立的随机口号。名字最多 16 字，不靠截断词语压长度。
- 同一词库版本、同一详情名和同一商品 code 组合得到相同结果，选品顺序不影响名字。
- 现有作品保存 `naming` 快照；更新词库时不覆盖作品原有名称、口号或票数。
- 不从网页实时拉取词库，不调用在线模型。新一轮热点须离线核验后显式更新版本。

## 旧记录

保留原算法只为兼容升级前的本地作品。旧账本首次加载时还原旧名并保存快照。
新账本与新组合默认使用 V2；组合身份继续由排序后的商品 code 确定。

同名餐名可能来自不同组合，用既有组合短编号区分；不把餐名当成存储键。
